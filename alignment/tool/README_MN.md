# Czech800 Tool v0.1 — Windows (Монгол заавар)

Энэ нь Google Drive дахь 810 OCR мөрийн бэлэн Чех үг, өгүүлбэр, Монгол орчуулгыг 7 цаг 26 минутын MP4 ба M4A файлуудын дуут хэсэгт холбох **өөрийн хэрэгсэл** юм.

**Статус:** Эхний pilot (туршилтын) код, хэрэглэгчийн Windows компьютер дээр одоогоор туршиж баталгаажуулаагүй. 6,400 клип бүтсэн, эсвэл миллисекундын алдаа баталгаажсан гэж үзэж болохгүй.

## Хэрэгтэй зүйл (өмнө суулгасан)
- Windows 11, RTX 2070 Super 8GB, NVIDIA Driver 621.14
- Python 3.11: D:\Czech800\.venv
- FFmpeg 9.0.1, Faster-Whisper, CTranslate2 болон cuBLAS/cuDNN
- Эх MP4: D:\Czech800\raw\Czech800.mp4
- Эх M4A: D:\Czech800\raw\Czech800.m4a

## Эхлэх нь — 4 алхам
1. [Төслийн энэ branch-ийг нээ](https://github.com/enkhbat194/Czech-Eba/tree/feat/czech800-alignment-pilot). **Code → Download ZIP** сонго.
2. ZIP-ийг задлаад **alignment\tool** хавтсыг нээнэ.
3. **INSTALL.cmd** дээр давхар дарж суулга. Энэ нь D:\Czech800 дотор аль хэдийн байгаа Python орчныг ашиглан код, 810 мөрийн орчуулга, эхний 20 үгийн өмнөх large-v3 хугацааны тайланг татна. Эх видео/аудиог дахин татахгүй.
4. **START_PILOT.cmd** дээр давхар дар. Эхлээд MP4/M4A аудионы 3 цэгийн синхрон шалгалт, 20 үгийн ногоон дэлгэцийн заагийг тодорхойлох, өмнөх large-v3 үр дүнг import хийх, browser-д Review хэрэгсэл нээнэ.

Хэрэв Windows хамгаалалт гарахад файлаа GitHub дахь өөрийн repo-оос авсан, кодыг таньж байгаа тохиолдолд л зөвшөөр. Санамсаргүй бусад сайтаас .cmd татаж ажиллуулахгүй.

## Browser дотор ажиллах
- Нэг үгийн Чех нэр, Монгол тайлбар, жишээ болон Монгол орчуулга харагдана.
- Тухайн видео хэсэгт шилжиж болно, ASR хэлсэн өгүүлбэрийг сонсож болно.
- Start / End цагийг 0.001 секундын **бичиглэлийн** нарийвчлалаар засах боломжтой.
- **Шалгаад батлах** дарсан хэсэг л exported WAV болно.
- Дараа нь **EXPORT_APPROVED.cmd** ажиллуул: D:\Czech800\output дотор зөвшөөрсөн lossless WAV + JSON/CSV гарна.

## Чех хэлний тусгай Forced Alignment
1. Эхний pilot-ийн **START_PILOT.cmd**-ийг ажиллуулсны дараа **INSTALL_ALIGNMENT.cmd** дарна. Энэ нь тусдаа D:\Czech800\.venv-align Python орчинд WhisperX суулгана (том таталттай, OPTIONAL).
2. **ALIGN_FIRST20.cmd** дарна. Чех \`comodoro/wav2vec2-xls-r-300m-cs-250\` CTC загвараар бэлэн эх Чех өгүүлбэрийг дууны авиануудтай тааруулж эхлэл/төгсгөлийг илүү нарийвчлалтай санал болгоно.
3. **START_PILOT.cmd**-ийг *дахин* ажиллуулахгүйгээр CMD-ээс \`D:\Czech800\RUN.cmd review\` нээж aligned candidate-уудаа шалгана. Review UI нь CTC-ийн санал болгосон хугацааг харуулах боловч автоматаар баталгаажуулахгүй.

> Гол санамж: Forced Alignment нь үг тексттэй үнэхээр таарсан, ASR-ийн ойролцоох хүрээ зөв үед л илүү үр дүнтэй. Таслагдсан фонем эсвэл дараагийн үг орсон эсэхийг сонсоно.

## Дараагийн үгсийг боловсруулах
**START_NEXT20.cmd** → 21–40-р мөрийн rough OCR хүрээнд Faster-Whisper medium GPU танилтыг ажиллуулна. Энд Монгол текст шинэчлэгддэггүй, хадгалсан эх өгөгдөл хэвээр.

## Командын сонголтууд (хөгжүүлэгчид)
- \`RUN.cmd check\` — эх медиа, GPU, бэлэн dataset
- \`RUN.cmd sync\` — MP4 vs M4A аудионы 3 газар cross-correlation
- \`RUN.cmd scan --limit 20\` — ногоон үгийн картын солигдолтын урьдчилсан илрүүлэлт
- \`RUN.cmd seed\` — бэлэн Whisper large-v3 20 үгийн candidate import
- \`RUN.cmd transcribe --start 41 --limit 60 --model medium\` — тухайн хүрээнд шинэ танилт
- \`RUN.cmd transcribe --limit 0 --model medium\` — 810 мөрийг тооцоолох; **pilot QA-д хүрэхээс өмнө хэрэглэхгүй**
- \`RUN.cmd review\` — http://127.0.0.1:8765
- \`RUN.cmd export\` — зөвхөн шалгаад баталсан WAV, CSV, JSON

## Чанар, хязгаар
- Drive-гийн \`audio_start_sec\` / \`audio_end_sec\` нь ярианы яг хил биш. 810 мөр = 810 бодит тусдаа үг гэж батлаагүй; давхардсан OCR фрагментүүд бий.
- Ялангуяа 1–20 үгийн \`first20_asr.json\` дотор дараагийн үг өмнөх үгийн хүрээнд орсон. Тиймээс candidate-уудыг сонсож, дүрстэй нь тулгаж засна.
- Whisper/WhisperX цагийг 3 орны нарийвчлалаар **бичиж чадна**, гэхдээ энэ нь ±1ms үнэн зөвийг **батлахгүй**.
- \`scan\` ногоон дэлгэцийн шилжилтийг дүрсийн өнгөөр илрүүлнэ. Энэ нь дүрсийн OCR биш; Чех үг, орчуулгын текстийг Drive дахь өмнө хийгдсэн OCR-оос уншина.
- \`sync\` шалгалт 3 байрлалд хийгдэнэ, бүх бичлэгийн абсолют баталгаа биш.
- \`transcribe\` Чех хэлээр ASR хийдэг; холимог англи тайлбарын үед буруу буулгах боломжтой.
- \`export\` зөвшөөрсөн WAV-ийг local-д гаргана; бичлэгийн зохиогчийн эрх эзэмших эсэхийг тусад нь баталгаажуулна. Эх CzechClass101 дууг олон нийтэд нээлттэй аппд эрхгүй түгээж болохгүй.
